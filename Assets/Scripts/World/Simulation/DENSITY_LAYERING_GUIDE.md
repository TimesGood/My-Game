# 液体密度分层配置指南

## 概述

新的物理模拟系统支持不同液体之间的密度分层效果。密度高的液体会沉到底部，密度低的液体会浮到上面。

## 密度配置示例

以下是一个典型的密度配置方案（数值越大，密度越高）：

| 液体 | 密度值 | 效果 |
|------|--------|------|
| 油 (Oil) | 10 | 浮在最上面 |
| 水 (Water) | 30 | 浮在油下面，岩浆上面 |
| 毒液 (Poison) | 50 | 沉在水下面 |
| 岩浆 (Lava) | 88 | 沉在最下面 |

## 配置步骤

### 1. 创建 MaterialPhysicsConfig 资源

1. 在 Unity 编辑器中，右键点击 `Assets/Data/Physics/` 文件夹
2. 选择 `Create > Physics > Material Physics Config`
3. 配置各种液体的物理属性

### 2. 设置密度值

在 `SimulationMaterialDefinition` 中设置 `density` 属性：

```csharp
// 油 - 低密度，浮在上面
new SimulationMaterialDefinition {
    movementMode = MaterialMovementMode.Liquid,
    density = 10,  // 低密度
    // ... 其他属性
}

// 水 - 中等密度
new SimulationMaterialDefinition {
    movementMode = MaterialMovementMode.Liquid,
    density = 30,  // 中等密度
    // ... 其他属性
}

// 岩浆 - 高密度，沉在下面
new SimulationMaterialDefinition {
    movementMode = MaterialMovementMode.Liquid,
    density = 88,  // 高密度
    // ... 其他属性
}
```

### 3. 配置其他属性

除了密度，还需要配置其他相关属性：

- `flowSpeed`: 流动速度（每秒更新次数）
- `canBeDisplaced`: 是否可以被其他液体置换
- `lateralProbability`: 横向流动概率

## 密度分层原理

### 向下流动时

当液体向下流动时，系统会检查下方液体的密度：

- **当前液体密度 > 下方液体密度**: 当前液体下沉，下方液体上浮
- **当前液体密度 ≤ 下方液体密度**: 不能下沉，保持原位

### 横向扩散时

当液体横向扩散时，系统会根据密度处理不同液体的接触：

- **密度大的液体**: 会下沉到底部位置
- **密度小的液体**: 会上浮到上面位置

## 示例场景

### 油水分离

1. 在同一个容器中同时放置油和水
2. 油（密度 10）会自动浮到水（密度 30）的上面
3. 形成分层效果

### 岩浆沉淀

1. 在水中倒入岩浆
2. 岩浆（密度 88）会沉到水（密度 30）的下面
3. 水会被抬升到上面

## 调试技巧

### 1. 使用调试器

添加 `LiquidSimulationDebugger` 组件，可以：
- 查看鼠标位置的液体信息
- 监控液体流动状态

### 2. 调整密度值

如果分层效果不明显，可以：
- 增大密度差异（如将油设为 5，岩浆设为 100）
- 调整 `flowSpeed` 控制流动速度

### 3. 检查配置

确保：
- 每种液体都有唯一的 `blockId`
- 密度值设置正确
- `movementMode` 设置为 `Liquid`

## 常见问题

### Q: 液体不分层？

A: 检查以下设置：
- 确认两种液体的 `density` 值不同
- 确认 `canBeDisplaced` 设置为 `true`
- 确认两种液体都配置在 `MaterialPhysicsConfig` 中

### Q: 分层后液体不流动？

A: 检查以下设置：
- 确认 `flowSpeed` 大于 0
- 确认 `moveProbability` 大于 0
- 检查是否有固体阻挡

### Q: 液体交换位置时闪烁？

A: 这是因为密度交换逻辑还在优化中。可以尝试：
- 减小 `flowSpeed`
- 增大密度差异
- 等待后续版本优化

## 密度参考值

以下是一些常见液体的密度参考：

| 液体类型 | 推荐密度范围 | 说明 |
|----------|--------------|------|
| 气泡/轻油 | 1-15 | 浮在最上面 |
| 水 | 20-40 | 中等密度 |
| 毒液/酸液 | 40-60 | 比水重 |
| 水银/熔融金属 | 70-90 | 很重 |
| 岩浆 | 80-100 | 最重 |

## 注意事项

1. **密度差异**: 密度差异越大，分层效果越明显
2. **流动速度**: 流动速度快会加速分层过程
3. **容器形状**: 狭窄的容器会加快分层
4. **性能考虑**: 大量液体分层可能影响性能，建议限制同时模拟的液体数量
